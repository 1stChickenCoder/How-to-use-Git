## 1. git init
- Chức năng: tạo repository mới trên máy tính

Repository là thư mục của github
Sau khi thực hiện xong máy tính sẽ tạo một thư mục ẩn có tên .git và code muốn đưa lên repo phải nằm cùng thư mục này thì nó mới được quản lý bởi git.

Có 2 loại repository: local và remote

## 2. git config

Có 2 loại config: local và global
Phạm vi của local hay global là đối với repo.

$ git config --local --list // in ra danh sách các config ở local.

$ git config --global --list // in ra danh sách các config ở global.

*Lưu ý: Cần config email và name ở local hoặc global để khi gửi code lên trên Github có thể nhận biêt được bản thân mình là ai.

$ git config --global user.name "Doan Duy Hoan"
$ git config --global user.email doanduyhoan@gmail.com

Khi config email không giống email trên github thì khi push code lên github sẽ xác định code của bản thân là một người khác thực hiện tác vụ với code đó.
