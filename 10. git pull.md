## Kéo code từ remote về local bằng `git pull`

Khi thực hiện commit trực tiếp trên remote (nhấn vào cái bút chì và thực hiện sửa trực tiếp ấy) thì local sẽ không có sự thay đổi.
Khi đấy thì thực hiện kéo code về như sau:
`$ git pull origin main`

Trong quá trình pull có thể có `conflict` thì phải xác nhận
- Accept Current Change
- Accept Imcoming Change
- Accept Both Changes
- Compare Changes

Sau khi thực hiện sửa conflict xong thì thực hiện
```bash
git add .
git commit -m "Confliction is fixed"
git push
```

Nếu mà push lên có `conflict` thì lại `git pull` code về và sửa.
Sau đó lại add, commit và push
