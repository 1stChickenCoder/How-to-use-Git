## Làm việc với các nhánh trong repo hiện tại

Để in ra các nhánh trong repo hiện tại
`$ git branch`

**Nhánh nào đang dùng sẽ được đánh dấu (*)**

Tạo nhánh mới
`$ git branch feature/branch_a`

Tạo nhánh mới và dịch chuyển đến nhánh mới luôn
`$ git checkout -b feature/branch_b`
hoặc
`$ git switch -c feature/branch_b`

Danh sách nhánh remote
`$ git branch -r`

Danh sách nhánh local
`$git branch -l`

Danh sách tất cả các nhánh cả remote cả local
`$ git branch -a`

Đôi khi máy tính không cập nhật các danh sách nhánh được (lag) thì sử dụng lệnh này để refresh lại
`$git fetch`

Dịch chuyển về nhánh `main`
`$ git checkout main`
hoặc
`$ git switch main`

Sửa tên nhánh
`$ git switch feature/my_branch`
`$ git branch -m feature/my_new_branch`
*Chỉ sửa được local nhé!

Xóa branch ở local
`$ git branch -D feature/my_branch`

Xóa branch ở remote
`$ git push origin --delete feature/delete_branch`

Đưa branch từ local lên remote mà không muốn push code lên
`$ git push -u origin feature/my_branch`

Sau khi xóa bằng tay một branch trên remote
