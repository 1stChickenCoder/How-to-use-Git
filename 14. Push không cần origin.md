## Push code không cần dùng origin

Khi checkout ra các nhánh khác không nằm trong nhánh chứa origin thì khi push code lên cần origin trong lệnh
Để bỏ qua thực hiện như sau

Giả sử đang checkout đến nhánh `feature/loginFunction`

Lần đầu tiên
`$ git push --set-upstream origin feature/loginFunction`
hoặc
`$ git push -u origin feature/loginFunction`

Các lần tiếp theo
`$ git push`
