## Gộp các nhánh bằng `git merge`

`$ git merge 'branchTargetName'`

*Lấy ví dụ sau: Có 3 nhánh
- main
- alpha: checkout từ main và có 2 commit D, E
- beta: checkout từ main và có 2 commit F, G
Thứ tự các commit theo chiều ngang được sắp xếp theo thời gian
```bash
(main)
A--B--C--D--E (alpha)
      |
      F--G    (beta)
```
Có thể thấy thứ tự thời gian 2 nhánh như sau:
- alpha: (main) A--B--C--D--E
- beta:  (main) A--B--C--F--G

Nếu ở beta muốn có những commit ở alpha
```bash
$ git checkout beta
$ git merge alpha
```
Khi đó sơ đồ sẽ thay đổi như sau
```bash
(main)
A--B--C--D--E (alpha)
      |    /
      F--G    (beta)
```

### Giải quyết xung đột khi merge
Giả sử branch A commit file me.txt, branch B commit file me.txt mà 2 files này có nội dung khác nhau thì khi merge 2 nhánh sẽ xảy ra xung đột.
Để giải quyết thực hiện những việc sau:
1. Tìm file conflict trong tab source và fix
2. git add . hoặc add từng file
3. Tiến hành thêm commit cho từng file vừa fix conflict bằng lệnh
`$ git merge --continue --no-edit`
nếu muốn edit thì 
`$ git merge --continue`
nếu muốn commit thì 
`$ git commit -m "message"`
4. Vào các nhánh và `$ git push` lên
