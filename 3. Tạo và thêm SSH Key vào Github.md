Khi muốn push code lên trên server cần có một remote repo và local repo phải kết nối với remote repo đó
Có 2 cách để kết nối remote repo:
1. Clone remote repo về local, lúc này thì ở local sẽ có local repo và đã được kết nối sẵn với remote
2. Dùng câu lệnh `$ git remote` để tạo môi trường liên kết

Clone thì thường có 2 cách:
1. Clone bằng SSH (nên dùng vì tiện và bảo mật)
2. Clone bằng HTTPS (phải gõ userName và password nên không bảo mật)

Cách 1 thì phức tạp hơn bởi ban đầu cần tạo key và add key

## Tạo SSH key

`$ ssh-keygen -t ed25519 -C "doanduyhoan@gmail.com"`
* -t ed25519: một loại thuật toán
* -C gán nhãn (comment) để nhận diện khóa, thường là email

*Gửi ra câu này trên terminal là đúng này:
```bash
Generating public/private ed25519 key pair.
```

Sau đó terminal hiện lên một yêu cầu

```bash

Thì nhập file lưu ssh key vì dụ như 
/c/Users/knt22443/.ssh/id_ed25519

```

Rồi nhập password

Sau đó nó sẽ trả ra một đường dẫn
/c/Users/knt22443/.ssh/id_ed25519.pub
Thì đây là file public ssh key

## Add prublic key vào github

Settings - SSH and GPG keys
New SSH key/Add new - Thêm tiêu đề - Nhấn nút Add

Kiểm tra xem ssh key đã được add hay chưa
`$ ssh -T git@github.com`

Nếu dùng nhiều tài khoản thì cần chỉ định
`$ ssh -T git@github-knt22443@local.nmcorp.nissan.biz`

```bash
// Hi HoanInNissan! You've successfully authenticated, but GitHub does not provide shell access.
```



**Giải quyết khi gặp lỗi permisson denied(publickey) khi thao tác với github**

Lưu ý: Nếu mọi người đổi tên file khác tên mặc định thì có thể Git nó sẽ không tự động tham chiếu đến cái file đó mỗi khi nó cần xác thực ssh key. Một số tên ssh key mặc định như: id_ed25519, id_rsa

Lúc này mọi người cần tạo thêm 1 file tên là config (không có đuôi mở rộng) nằm trong thư mục .ssh có dạng như sau.

Ví dụ như dưới đây, sửa id_duthanhduoc10 thành tên file private ssh key của bạn là được

```bash
#Default GitHub
Host github.com
HostName github.com
User git
IdentityFile ~/.ssh/id_duthanhduoc10
```
