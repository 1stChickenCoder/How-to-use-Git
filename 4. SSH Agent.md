## Trường hợp tạo SSH key với passphrases

Với SSH key, nếu ai đó truy cập được vào máy tính thì có thể truy cập được vào Github và thay đổi mã nguồn. Có thể thêm passphrase vào SSH key để tăng cường tính bảo mật. Khi thêm như vậy, mỗi lần push code thì Git đều yêu cầu nhập passphrase, hoặc có thể dùng một `ssh-agent` để chỉ cần nhập 1 lần passphare trong 1 phiên làm việc.

## Thêm hoặc thay đổi passphrase

Nếu tạo SSH key với passpharase thì không cần quan tâm đến cái này, còn nếu lúc tạo chưa có thì thực hiện.

Lưu ý thay thế tên `id_ed25519` cho đúng với file private

```bash
$ ssh-keygen -p -f ~/.ssh/id_ed25519
> Enter old passphrase: [Type old passphrase]
> Key has comment 'your_email@gmail.com'
> Enter new passphrase (empty for no passphrase)
> Enter same passphrase again: []
> Your identification has been saved with the new passphare
```

Lấy một ví dụ:
```bash
$ git clone "ssh-abc.com"
> Enter paraphrase:
...
Sửa code các thứ...
...
$ git add .
$ git commit -m "Fixed empty array"
$ git push
> Enter paraphrase:
...
```

Có thể thấy những yêu cầu nhập paraphrase là liên tục.

## Thêm SSH key vào ssh-agent

Để khởi động ssh-agent thì có 2 cách đó là mỗi lần mở Git bash thì khởi động nó hoặc setting cho nó khởi động tự động
*tuy nhiên các khởi động tự động có nhiều lỗi

### Khởi động ssh-agent

1. Mở Git bash và chạy lệnh sau

```bash
$ eval "$(ssh-agent -s)"
> Agent pid ...
```

2. Tiến hành thêm SSH private key vào ssh-agent. Thay thế `id_ed25519` cho phù hợp

`$ ssh-add ~/.ssh/id_ed25519`

3. Tiến hành thêm SSH key vào tài khoản Github. Nếu đã thêm rồi thì thôi

> **Tip**: Câu lệnh `ssh-add` tương đương với `ssh-add ~/.ssh/id_rsa`
>Muốn check ssh-agent đã chạy chưa thì thực hiện `ssh-add ~/.ssh/id_ed25519`. Nếu kết quả là "Could no open a connection..." thì là ssh-agent chưa chạy. Nếu yêu cầu nhập passphrase thì là chạy rồi
