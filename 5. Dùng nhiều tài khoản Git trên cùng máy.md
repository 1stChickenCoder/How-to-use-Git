## Dùng nhiều tài khoản Github trên cùng máy tính

Tạo 1 file `config` (không có đuôi extention) trong thư mục `~/.ssh/`
Viết nội dung dưới đây

```bash
#Default Github
Host github.com
HostName github.com
User git
IdentityFile ~/.ssh/id_rsa

#Something...
Host github-knt22443.com
HostName github.com
User git
IdentityFile ~/.ssh/id_rsa_knt22443
```
