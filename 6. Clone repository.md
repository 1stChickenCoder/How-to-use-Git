## Clone repository

1. Clone với HTTPS

Mở repo trên Github, chọn vào code, chọn vào HTTPS

`$ git clone https://github...com`

2. Clone với SSH

Mở repo trên Github, chọn vào code, chọn vào SSH
Nhớ là phải tồn tại SSH key trên Github

`$ git clone git@github.com...`

Nếu là một user khác với default

`$ git clone git@github-knt22443.com...`
