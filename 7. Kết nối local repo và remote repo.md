## Kết nối local repo và remote repo

Nói chung thì nó là push cái repo ở máy lên trên server thôi.

1. (Nếu chưa có thì tạo mới) Vào remote repo trên Github
2. Init và config local repo và truy cập vào local repo (thư mục chứa code ở máy)
3. Thực hiện đoạn lệnh

```bash
$ git remote add origin git@github.com... // đưa clone SSH vào
$ git branch -M main
$ git push -u origin main
```
*Lưu ý phần nhánh main cần lưu ý push vào. 
*Có thể điều chỉnh nhánh default: Setting - Repositories - 'Chọn nhánh' - Update
